# Programmatic SEO Metadata Template

Use these patterns for every city/niche page. Replace brackets with real values.

## Title tag (55–60 chars ideal)
```
10 Best [Niche] Services in [City], [State] [Year] | Local Directory
```
**Example:**
```
10 Best Mobile RV Repair Services in Dallas, TX 2026 | Local Directory
```

## Meta description (150–160 chars)
```
Find trusted [niche] near you in [City], [State]. Compare verified ratings, phones & websites for emergency, routine & mobile service. Updated [Year].
```
**Example:**
```
Find trusted mobile RV repair near you in Dallas, TX. Compare verified ratings, phones & websites for emergency, routine & mobile service. Updated 2026.
```

## H1
```
[Niche] in [City], [State]
```
**Example:**
```
Mobile RV Repair in Dallas, TX
```

## H2 options (use 2–4 per page)
- Top-Rated [Niche] Providers in [City]
- Emergency [Niche] Near Me
- Routine Maintenance & Mobile Mechanics
- How to Choose a [Niche] Service in [City]
- Frequently Asked Questions About [Niche] in [City]

## On-page SEO already baked into index.html
- JSON-LD `ItemList` + `LocalBusiness`
- Semantic `<article>` cards
- Clear internal CTAs for “Claim” and “Add”
- Mobile-first layout and fast load (no heavy frameworks)

For additional city pages: duplicate `index.html`, change the title/description/H1, swap the `LISTINGS` array, and update the canonical URL.
